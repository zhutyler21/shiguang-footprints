让照片在地图上留下足迹

照片与记录保存在本机。高德地图需要联网和有效的 Web 端 Key。

  1. 登录 高德开放平台控制台，创建应用并添加 Web 端（JS API） 类型的 Key。
  2. 在项目目录复制配置模板：
    cp .env.example .env
    如果已存在 .env，请直接编辑，保留已有配置。
  3. 在本地编辑 .env，填写与同一个 Key 配套的两项配置：
    AMAP_KEY=你的Web端Key
AMAP_SECURITY_CODE=对应的安全密钥
PORT=3001
    安全密钥由服务端代理使用，不会下发到浏览器。
  4. 停止已运行的服务，重新执行 npm run dev。访问 http://127.0.0.1:5173/。如果使用构建后的版本，则执行 npm run build 和 npm start，访问 http://127.0.0.1:3001/。
  5. 地图出现后，上传照片，检查自动定位或点击地图选点，勾选“我已确认地图上的位置”，保存打卡。

如果地图加载失败，检查网络、Key 类型、配套安全密钥以及控制台的域名访问限制。参考 高德官方安全代理配置。不要把密钥发到聊天或提交 Git。
